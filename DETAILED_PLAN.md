## Этап 4: Сценарное взвешивание (AHP + WLC)
**Цель:** Рассчитать агрегированные индексы пригодности ($S_{ik}$) для разных типов использования по нескольким сценариям.

1. **Рефакторинг AHP модуля (`ahp.py`)**:
   - Переход от единого балла привлекательности к массиву баллов для каждого типа использования (парк, жилье, коммерция, хаб).
   - Внедрение формулы Weighted Linear Combination (WLC) с учетом бинарных ограничений ($C_{ij}$).
2. **Настройка сценариев в `configs`**:
   - Создание конфигурационных пресетов для трех сценариев: *Экоцентризм*, *Историко-центризм*, *Инфраструктурный*.
   - Валидация отношения непротиворечивости (CR $\le 0.10$) для каждого пресета.
3. **Тестовый прогон**:
   - Генерация промежуточного GeoJSON с матрицей баллов $S_{ik}$ для проверки корректности математики.

---

## Этап 5: Глобальная оптимизация (Имитация отжига)
**Цель:** Разрешить пространственные конфликты и назначить оптимальный `Target Land Use`.

1. **Интеграция модуля оптимизации BlocksNet**:
   - Разработка скрипта (например, `src/analysis/optimizer.py`), который принимает на вход матрицу баллов $S_{ik}$ и матрицу доступности.
2. **Настройка целевой функции**:
   - Формализация глобальной цели (максимизация полезности при минимизации времени в пути между функциями).
   - Запуск алгоритма `Simulated Annealing` (имитация отжига) для распределения типов землепользования.
3. **Вычисление Capacity (Расчетной мощности)**:
   - Преобразование итоговых баллов в параметр обслуживающей емкости.
4. **Финальная сборка датасета**:
   - Формирование итогового `ucm_blocks_optimized.geojson`, содержащего предписанный тип (`Target_LandUse`), баллы по альтернативам и мощность.

## Этап 6: Интерактивный дашборд (Streamlit + Folium)
**Цель:** Создать динамический UI для стейкхолдеров.

1. **Обновление `app.py`**:
   - Добавление переключателя сценариев (Экоцентризм, Историко-центризм, Инфраструктура) в боковую панель.
   - Настройка кэширования для предрассчитанных конфигураций графов и блоков (`@st.cache_data`).
2. **Динамический рендеринг и категоризация цветов (Folium)**:
   - Переход от линейного градиента к категориальной палитре (`style_function` на основе `Target_LandUse`): зеленый — парки, синий — хабы и т.д.
   - Оптимизация передачи GeoJSON (отбрасывание лишних колонок).
   - Использование `feature_group_to_add` для мгновенного обновления слоев без перезагрузки всей страницы.
3. **Интерактивные всплывающие окна (Popups)**:
   - Обновление HTML-карточек: вывод текущей статистики, предписанного типа застройки, матрицы пригодности ($S_{ik}$) и расчетной мощности.
