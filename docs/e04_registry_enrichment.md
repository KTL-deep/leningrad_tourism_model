# E04: официальные каталоги и рекомендательные связи

Первый срез E04 расширяет сохранённый RunManifest E03, не перезаписывая исходный запуск, POI или PBF. Этап E04 остаётся **partial**.

## Запуск

```powershell
.\.venv-app\Scripts\python.exe -X utf8 -m scripts.enrich_territory --store data/analysis/e03_acceptance_20261024 --run-id 83b23ec38a764a3f8318bb8a00c18f24
```

Повтор с `--offline` использует проверенные снимки и действующий кэш. Отсутствующий, просроченный или повреждённый кэш не заменяется вымышленными данными. Сбой отдельного источника не отменяет независимые наблюдения; причины сохраняются в журнале и дочернем манифесте.

## Источники и ограничения

- **ЕГРОКН Минкультуры:** публичный ZIP с JSON-массивами (приоритетный формат) либо JSONL, скачиваемый без API-ключа по ссылкам, объявленным официальным паспортом. Весь национальный архив сканируется до EOF с проверкой CRC; сохраняются записи регионов 47/78, а не первые 1000 объектов веб-карты. Региональный каталог не считается целиком расположенным внутри запрошенной территории.
- На 26.10.2026 объявленный `data-70-structure-17.jsons.zip` отвечает 404; объявленный в истории того же паспорта `data-70-structure-16.jsons.zip` доступен. Фактически выбранные версия данных и структура фиксируются отдельно. Одинаковые байты схем 16/17 не устанавливают соответствие их номеров непрозрачным `odSchema` записей.
- Полная проверка **JSONL-архива** выявила некорректный размер ZIP-member: объявлено 909 567 863 байта, фактически поток DEFLATE содержит 1 309 271 909. `zipfile` сообщает `Bad CRC-32`; независимое диагностическое чтение полного DEFLATE даёт CRC `e2cddd35`, совпадающую с заголовком, но не устраняет ошибку размера. Этот архив **отклонён**. Исходный ZIP не исправлялся, проверка целостности не отключалась; ниже описан отдельный корректный JSON ZIP.
- GeoJSON-точки интерпретируются как longitude/latitude с явным предупреждением о противоречащей подписи `lat,long` в схеме источника. Это не границы, входы или доказательство доступности. Неразмещённые записи сохраняются.
- **ООПТ Ленинградской области:** HTML-каталог официального комитета содержит 55 записей (51 региональную, 4 местные). Используется содержательная статья без повторов навигации. PDF-перечень — скан; геометрии, попадание записей внутрь территории и действующие правовые режимы не установлены.
- Дата получения OSM остаётся исходной, а не датой обогащения. Временная согласованность источников не подтверждена.

## Сопоставление

Явные национальные номера из `ref:egrokn` и `ref:ru:heritage` образуют связи по идентификатору; неоднозначные номера не разрешаются выбором первого объекта. Точные нормализованные названия и геодезическое расстояние дают лишь кандидатов на проверку. Числовые пути сайтов КГИОП не считаются национальными номерами.

Объекты не объединяются. Не вычисляются вместимость, число уникальных физических объектов, полнота/точность сопоставления, разрешения на посещение или туристические рекомендации. Независимая контрольная выборка ещё не подготовлена. Население, посещаемость, размещение и разрешённый маршрут отзывов остаются отдельной незавершённой частью E04.
