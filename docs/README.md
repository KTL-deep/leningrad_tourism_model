# Документация проекта

Единая актуальная постановка — [мастер-план v1.1](../TOURISM_FRAMEWORK_CODEX_MASTER_PLAN.md). Функция считается реализованной только по коду и проверкам, а не по наличию описания.

| Документ | Назначение |
| --- | --- |
| [implementation_status.md](implementation_status.md) | Этапы E00–E16, реальные результаты, ограничения и точное продолжение |
| [pilot_scope.md](pilot_scope.md) | Павловск — Гатчина, юрисдикции, сущности и единицы |
| [data_sources.md](data_sources.md) | Реестр источников, реальные ответы и роли наборов в расчётах |
| [methods_matrix.md](methods_matrix.md) | Основания методов, допущения и статус проверки литературы |
| [legal_rules.md](legal_rules.md) | Нормативные проверки; unknown не означает разрешение |
| [requirements_traceability.md](requirements_traceability.md) | Требования и приёмочные проверки |
| [validation.md](validation.md) | Воспроизведение тестов и известные дефекты |
| [performance_osm.md](performance_osm.md) | Измерения OSM-парсера и проверка целесообразности Rust |
| [evidence_register.csv](evidence_register.csv) и [references.bib](references.bib) | Свидетельства и переносимая библиография |
| [decisions/](decisions/) | История принятых архитектурных решений (ADR) |

Устаревшие `ARCHITECTURE.md`, `PROJECT_GUIDE.md` и `DETAILED_PLAN_v3.md` удалены по просьбе автора. Они описывали прежнюю концепцию и дублировали мастер-план с противоречащими ему утверждениями. Полезный исходный код, научные источники, журнал и результаты проверок сохранены. История решений не заменяет текущую версию методики.
