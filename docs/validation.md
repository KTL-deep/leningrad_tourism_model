## Принятие методики — 2026-10-19 (документация)

Принята целевая политика бесплатного автоматического многоисточникового ядра: отчёт Павловска и полный D/K не являются условием завершения разведки источников или обязательными входами будущего запуска. Официальная статистика включается численно только при автоматическом получении с проверенными происхождением, периодом, единицами, охватом и условиями; разрешённый проверенный кэш — с датой/качеством. Иначе исключить набор, записать unknown/причину, продолжить сокращённый/условный анализ без нуля или ручного CSV. Неизвестные правовые условия не дают разрешения, а обязательные геометрия/сеть остаются необходимыми. Отзывы — только необязательный слой из разрешённых API/поставщиков, не прокси посещений/D/K; число оценок, текстов и размер корпуса раздельны, дата публикации не равна дате визита, темы требуют подтверждения. Документация Yandex Organization Search API не описывает тексты отзывов; платный продукт не является обязательным или подтверждённым API отзывов. Исторические результаты PDF Гатчины выше сохранены как необязательная проверка, не зависимость конвейера. Многоисточниковый поиск и адаптеры отзывов ещё не реализованы; этот раздел фиксирует решение, **не новый запуск тестов** и не перевод E01 в done.
