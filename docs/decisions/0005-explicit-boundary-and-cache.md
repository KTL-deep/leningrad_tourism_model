# ADR 0005 — Геометрический контракт и первый автоматический пространственный вход

Дата: 2026-10-19. Статус: принято для ограниченного среза E02/E03.

1. StudyArea v1 принимает только явный EPSG:4326 и валидный непустой Polygon/MultiPolygon. Запрещены Point, самопересечения, незамкнутые кольца, нечисловые/нефинитные/3D координаты и скрытая перепроекция. Вложенная CRS не игнорируется. Метрическая CRS, если задана, должна иметь проецированные метровые оси; величины площади/длины в градусах не вычисляются.
2. Геометрии нормализуются, внутренне неизменяемы, наружу выдаются копии. ID не зависит от отображаемого имени, но зависит от геометрии и контекста/окружения/юрисдикций/CRS. Заданный analysis_geometry должен покрывать запрос; без него surrounding_status=not_configured. Ни окружение, ни буфер произвольно не создаются.
3. Юрисдикции из адресных данных OSM помечаются source_reported, не verified. Проверка геометрии не устанавливает юридическую границу или допустимость строительства. StudyArea.from_dict проверяет версию, набор полей, идентичность и статус окружения.
4. Первый поддерживаемый адаптер — один явный территориальный запрос Nominatim, не универсальный адресный поиск. Из выдачи выбирается единственный поддерживаемый территориальный полигон, не первый результат: станция/здание исключаются, несколько разных полигонов дают ambiguous_boundary, конфликт одного OSM ID не замалчивается.
5. Идентифицированный User-Agent, TLS, ограниченный ответ (2 MiB), таймауты и отсутствие редиректов/автоматических повторов. Смена endpoint возможна оператором; для нестандартного нужны подтверждённые им условия. Ключ кэша включает endpoint, нормализованные параметры и версию адаптера. Публичный сервер не превращается в generic-сервис, bulk/периодический геокодер или POI-перечислитель.
6. Fresh-кэш перепроверяется по метаданным/хэшу, исходным байтам, query URL и заново построенному StudyArea. Рабочая TTL — техническая настройка свежести, по умолчанию 24 часа, не доказательство срока действия границы. Сбой не заменяет прошлые данные пустыми и не удаляет старый указатель/снимки. Offline не обращается в сеть. Повреждённый/чужой кэш — явная ошибка, не автоматический повтор.
7. Запросы сериализуются собственным lock в общем каталоге кэша; между стартами минимум 1,1 с, состояние сохраняется между CLI-процессами. Будущая/повреждённая временная метка не вызывает бесконечное ожидание. Чужие/аварийные lock не удаляются автоматически. Для параллельных инсталляций с разными кэшами лимит суммарно не обеспечивается — такой режим запрещён для публичного сервера, не обещается масштабирование.
8. Snapshot.retrieved_at — время начала первого успешного получения неизменяемого ответа; observed_at кэша — начало последней успешной проверки. Это не точное время публикации или вступления границы в силу. Входной period_basis для границы обозначает только системное наблюдение источника, не период статистического показателя.
9. CLI collect_boundary связывает реальный ответ со StudyArea, политикой допуска и RunManifest. Полнота относится только к выбранному полигону, не ко всем объектам территории. boundary_status может быть succeeded, но общий результат partial; input_assessment остаётся failed без обязательного poi. computed_tourism_results пуст, analysis_performed=false. Это не скрытая замена полного расчёта одной демонстрационной картой.

Первый срез не включает временные/лицензионные миграции всех контрактов, POI/сеть, обоснование окружения, автопоиск статистики, слой отзывов, полный оркестратор и UI. Они остаются следующими задачами. Фактические прогоны и оставшиеся дефекты — в журнале и validation.
