# ADR 0002 — Проверяемые источники до калибровки модели

Дата: 2026-10-19. Статус: принято для E01; не заменяет контракты E02.

**Уточнено ADR 0003:** [многоисточниковое ядро и необязательная статистика](0003-multisource-optional-statistics.md). Ниже сохранено историческое решение и факты проверки. Его указание ждать D/K/расписаний для завершения разведки не является текущим глобальным блокером: отсутствующая статистика исключается из расчёта с причиной, а не блокирует независимый анализ. Политика вычислимости конкретных показателей и правовые ограничения сохраняются.

## Контекст

У проверенных источников разные реальные состояния: официальный PDF Гатчины доступен и разбирается, паспорт ЕГРОКН доступен без полученных записей, несколько endpoint имеют ошибки TLS, страница Павловска возвращает JS-проверку. Успех HTTP сам по себе не означает загрузку данных.

## Решение

1. Каталог кандидатов хранить в `configs/source_probes.json`, повторяемые наблюдения — в отдельном новом файле `data/audit/` на каждый запуск. Probe не является production-адаптером или неизменяемым снимком данных. Не перезаписывать предыдущий журнал и не обходить ограничения источника.
2. Для первого официального документа реализовать узкий адаптер Гатчины, а не универсальное извлечение любых PDF. Сохранять единицы источника, PDF-страницу, дословный фрагмент, период, SHA-256 и версию адаптера. При неизвестной/изменённой подписи или неоднозначности — ошибка, не ноль.
3. Не складывать 728000 из общего показателя и 202282 посещения парка по абонементам: уникальность и пересечение не установлены. Не использовать их как готовый D туристических услуг в час или как эффект мероприятия.
4. Для будущей границы Павловска проверять полигональную геометрию и юрисдикцию; первая позиция Nominatim оказалась станцией. Стабильный OSM ID не является доказательством правовой границы. Полные снимки границ и кэш геокодирования — E02/E03.
5. У метода ограниченного распределения из S7 проверены разделы, а не вся публикация. Перенос с зелёных пространств на сервисы — адаптация с собственными единицами и проверкой. Ни один численный норматив из статьи пока не переносится.
6. Матрица нормативов содержит unknown до проверки действующей редакции, пункта, геометрии и действия. Отсутствие документов не становится разрешением. Экоцентризм трактуется как этическая позиция по академическому источнику S9, а не как вес леса.

## Последствия

Новый поток извлечения работает независимо от старого конвейера и не меняет его расчётные файлы. Первый доказанный результат — трассируемое извлечение двух отчётных значений, не прогноз и не карта мероприятий. E01 остаётся partial до достаточного плана реальных D/K/расписаний и первых независимых проверок эффектов. Технические схемы E02 должны опираться на эти фактические ограничения.
