# ADR 0008 — Ограниченный резерв OSM из регионального PBF

Дата: 2026-10-23. Статус: решение принято; реализация и live-проверка фиксируются отдельно в журнале.

## Причина

Повтор `scripts.collect_osm` для Гатчины 23.10.2026 завершился таймаутом Overpass. Граница сохранена, POI/дороги исключены, `analysis_performed=false`; run `e8759672337a41e9ac4806c985516718`. Перебор зеркал не является стратегией восстановления.

## Решение и границы

- Поддержать отдельный резервный путь через публичную [выгрузку Geofabrik для Северо-Запада](https://download.geofabrik.de/russia/northwestern-fed-district.html), без логина и пользовательских файлов. Это регионально ограниченный адаптер, не универсальный загрузчик всего мира.
- Лицензия исходных данных — ODbL 1.0; атрибуция `© OpenStreetMap contributors`, публикатор Geofabrik. На публичном сервере удалены user/uid/changeset. Закрытые выгрузки и история с персональными метаданными не используются.
- [Техническая документация](https://download.geofabrik.de/technical.html) описывает ежедневные PBF, полигон вырезки `.poly` и дату базы в заголовке. Полигон вырезки проверяет покрытие источника, но не заменяет административную границу или обоснование транспортного окружения.
- Размер опубликованного PBF около 625 МБ, меньших подрегионов у поставщика нет. Нужны потоковая загрузка с явным лимитом, проверка длины/хэша, ограниченные таймауты, атомарная публикация и проверяемый локальный кэш. Автоматическое скачивание нескольких регионов или зеркал не допускается.
- `latest` при проверке HEAD отвечает 307 на датированный файл того же сервера. Допустим только один проверенный переход на HTTPS `download.geofabrik.de/russia/northwestern-fed-district-YYMMDD.osm.pbf`, без параметров/учётных данных. Произвольные редиректы не разрешаются; исходный и разрешённый URL сохраняются.
- Разбор PBF выполняется локально через osmium. Нельзя держать все узлы федерального округа в Python-словаре или загружать весь файл в память ради bytes-API хранилища.
- Если поддержаны только node/way-наблюдения, relations явно отмечаются как неподдерживаемые, инвентаризация остаётся partial. Ни число POI, ни полные ссылки дорожных линий не означают полноту реальных услуг или готовую маршрутизацию.
- Нельзя выдавать нормализованный промежуточный JSON за исходный ответ Overpass. Файловый PBF-манифест без интеграции в SourceSnapshot/RunManifest должен быть явно обозначен как ограниченный срез, а не полное выполнение E02/E03.

## Проверенное до реализации

Прочитаны страницы региона и техническая документация. Прямой запрос `.poly`: HTTP 200, 20729 байт, SHA-256 `f0bfe24419b815027130c93ea39aad42bc51351ba2ef867cac6f7743ec969cf7`. HEAD `latest` дал 307 на `northwestern-fed-district-261021.osm.pbf`. Это подтверждение маршрута/метаданных, **не успешная загрузка или разбор PBF**. Журнал: `data/audit/geofabrik_preflight_20261023.json`.

Результаты реализации, тестов и реальной загрузки — в [validation](../validation.md) и [журнале](../implementation_status.md). E03 до выполнения оставшихся критериев остаётся partial.
