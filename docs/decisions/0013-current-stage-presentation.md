# ADR 0013 — Интерфейс текущего среза E03/E04

Дата: 2026-11-02. Статус: принято для подготовки демонстрации текущей разработки.

## Контекст

Автору нужен интерфейс для презентации актуального состояния на следующей неделе. Старый `app.py` показывает AHP/SA baseline; новый конвейер уже сохраняет пространственные наблюдения и рекомендательные сопоставления, но не вычисляет маршруты, дефициты или мероприятия. Внешняя сеть и API не должны определять успех показа сохранённых результатов.

## Решение

- Сохранить baseline в `app.py`; добавить отдельный `current_app.py`. `run_app.bat` запускает новый экран в полном `.venv-app` с привязкой к папке скрипта и loopback-адресу.
- Использовать `SnapshotStore`: каталог запусков читает метаданные и проверенные конфигурации, выбранный запуск проходит `get_run` с проверкой всех ссылок и потоковых хэшей, затем загружаются только ограниченные по размеру JSON/GeoJSON. Изменяемые пути экспортов не являются запасным источником данных.
- Проверять принадлежность POI/дорог/сопоставлений области и манифесту, конфигурационный хэш, источник родительского запуска и POI сопоставления. Повреждения и неподдерживаемая форма дают ошибку, а не карту с нулями.
- Кэшировать лишь каталог на 30 секунд. Проверенные результаты не кэшировать: каждый rerun повторно проверяет архив, чтобы повреждение после загрузки не скрывалось прежним результатом.
- Карту строить нативным Vega-Lite из встроенных геометрий, без тайлов, CDN, коммерческой лицензии или API-ключа. Граница запроса, область первичного сбора, линии дорог и POI не означают маршруты или юридическую геометрию. Проекция — только визуализация.
- Показывать даты архива и неизвестность. ID-связи, кандидаты и исключённые пары разделять; неизвестное расстояние не заменять нулём. Скачать можно Markdown-отчёт и JSON-паспорт со снимками и ограничениями.

## Критерии приёмки среза

Синтетические проверки охватывают отсутствие/повреждение архива, неправильные ссылки/форматы, независимость от экспортных файлов, unknown, карту без внешних URL и переключения UI. Реальные архивы обоих пилотов читаются с проверкой хэшей; браузерный показ карты проверяется с заблокированными внешними HTTP-запросами. Счётчики UI получаются из выбранных артефактов, а не из констант презентации. Результаты прогонов фиксируются в журнале.

## Ограничения

Это подготовительный просмотрщик существующих результатов, не готовый E13. Сбор/обогащение запускаются существующими CLI, не экраном. Архивы игнорируются Git; пустой клон без них не выдаёт демонстрационных данных. Полная проверка PBF при каждом rerun имеет цену по времени/дисковому чтению; ради надёжности не вводится непроверенная оптимизация. Для повторного сетевого сбора остаются настоящие TTL и политики источников. Полный офлайн-показ не доказывает актуальность туристических объектов, точность сопоставления или научную новизну.
