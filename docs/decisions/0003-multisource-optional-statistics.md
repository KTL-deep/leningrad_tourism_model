# ADR 0003 — Многоисточниковое ядро и необязательная официальная статистика

Дата: 2026-10-19. Статус: **согласовано с автором**. Уточняет ADR 0001/0002; заменяет прежнюю последовательность, в которой поиск конкретного музейного PDF фактически становился условием продолжения E01.

## Основание

Автор отклонил зависимость анализа от отдельного отчёта Гатчины и согласовал общий многоисточниковый подход для разных территорий. Дополнительное указание: официальную статистику включать, только если программа может найти её сама, иначе исключать.

Проверена документация Яндекса: [формат ответа API организаций](https://yandex.ru/maps-api/docs/geosearch-api/response.html) не документирует тексты отзывов; [продукт](https://yandex.ru/maps-api/products/geosearch-api) лицензируется. Это не подтверждённый бесплатный API массовой выгрузки отзывов. [Справка отзывов](https://yandex.ru/support/business-priority/ru/manage/reviews) различает оценки и текстовые отзывы, указывает ограничение просмотра последних 600 отзывов; доступное окно не является полной историей посещений.

## Решение

1. **Одна модель данных и процесс для территорий; сменные поддерживаемые источники.** Базовое ядро не требует платы, LLM, личного кабинета, ручного CSV или отдельного PDF. Универсальность не означает универсальный парсер любого сайта или гарантированное полное покрытие.
2. **Официальная статистика — необязательное обогащение.** Программа сама ищет её по поддерживаемым каталогам/адаптерам с ограниченным бюджетом попыток. Набор включается, только когда автоматически получен и проверены источник/права, территория, период, единицы и покрытие. Пригодный разрешённый кэш допускается с явными датой и качеством.
3. **Не найдено/не получено/не прошло проверку — исключить набор из численного расчёта**, сохранив причину, время попытки, ограничения и unknown. Не заменять неизвестность нулём, не запрашивать документ у пользователя и не блокировать независимые расчёты.
4. **Исключается набор, а не методическая честность.** Без оснований D/K не вычислять количественный U/эффект как факт. Можно показывать проверенный каркас/доступность и исследовательские сообщения, а условные оценки выполнять только при обоснованных предпосылках с единицами/диапазонами. Провал необходимой геометрии/сети ограничивает соответствующий расчёт. Правовые проверки не относятся к необязательной статистике: unknown не разрешает строительство.
5. **Отзывы — дополнительный проверяемый слой опыта/активности.** Подключать разрешённые API/выгрузки после подтверждения прав на сбор, хранение и аналитику; менять поставщиков без привязки ядра к Яндексу. Не считать отзыв визитом, публикацию датой визита, рейтинг вместимостью или жалобу доказанным U. Разделять rating_count, text_review_count и размер реально полученного корпуса. Темы/тональность — производные сигналы с независимой проверкой, не установленные события.
6. **Яндекс пока только кандидат.** Наличие стороннего клиента, cookies, виджета или данных в интерфейсе не подтверждает поддерживаемый разрешённый API отзывов. Не обещать его реализацию и не обходить ограничения. Отсутствие доступа оставляет слой недоступным, не требует обязательной покупки.
7. **Сохраняем факты аудита.** Узкий адаптер Гатчины, тесты и хэши не удаляются: это необязательный контрольный пример. Не требовать аналогичный отчёт для каждого города. Прошлые ADR и результаты сохраняются с отметкой об уточнении политики.

Исключённый набор не удаляет причину недоступности из отчёта и не вызывает скрытого перераспределения весов; сравнение требует общей явно показанной базы. Найденный вручную разработчиком пилотный URL и узкий адаптер не являются реализованным автоматическим поиском статистики.

## Реализация и критерии проверки

На момент принятия изменены методика и документация, **не реализованы** универсальное обнаружение, оркестрация исключения наборов и адаптеры отзывов. Старый main.py не соответствует этому решению. E01 остаётся partial; его дальнейшая оценка ведётся по v1.1, без искусственного блокера «найти PDF Павловска/полную статистику D/K».

Проверки новой реализации: T11 — статистика не найдена/невалидна, расчёт продолжается только в поддерживаемом объёме; T12 — отзывы недоступны/усечены, нет ложной полноты и обязательной покупки; T13 — жалоба без D/K остаётся сообщением, не выдуманной количественной рекомендацией. Дополнительно проверить второй населённый пункт без музейного отчёта и сохранение правовых запретов в частичном режиме. Эти проверки пока запланированы, не считаются выполненными по изменению Markdown.
