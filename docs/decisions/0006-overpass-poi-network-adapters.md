# ADR 0006 — Overpass-адаптеры для POI и дорожной сети

Дата: 2026-10-19. Статус: принято.

**Уточнение после проверки рабочего дерева:** ниже сохранено исходное черновое решение. Файлы двух адаптеров оставлены без перезаписи, но новый CLI их не использует: POI-черновик теряет меньшие части MultiPolygon, сетевой соединяет внешние кольца разных частей в один poly-фильтр; проверка полноты ответа недостаточна. Их импортируют только собственные тесты. Текущий путь — совместный ограниченный запрос/парсер и ADR 0007. Наличие старого `completeness=complete` не подтверждает действительную полноту.

## Контекст

E03 требует автоматической загрузки OSM POI и транспортной сети для пилотных территорий. Старый код (src/etl/osm_loader.py) использовал OSMnx, который:
- не интегрирован с новым SnapshotStore и контрактами происхождения;
- не контролирует покрытие, не хранит неизменяемые снимки;
- зависит от тяжёлых пакетов (osmnx, networkit, blocksnet), не установленных в audit-окружении.

Nominatim-адаптер (ADR 0005) уже реализовал паттерн: кэш с TTL, rate limiting, SnapshotStore, offline-режим и DatasetCandidate-интеграция.

## Решение

Создать два отдельных адаптера прямого доступа к Overpass API:

1. `src/etl/adapters/overpass_poi.py` — загрузка точек интереса (amenity, tourism, historic, leisure, shop) с подсчётом по категориям.
2. `src/etl/adapters/overpass_network.py` — загрузка дорожной сети (highway), ж/д (railway) и маршрутов ОТ (route) с геометрией рёбер.

Оба адаптера:
- Используют прямой Overpass QL запрос с `poly:` фильтром по границе StudyArea.
- Сохраняют сырой JSON-ответ как неизменяемый снимок через SnapshotStore.
- Реализуют файловый кэш с TTL и проверкой идентичности.
- Соблюдают rate limiting (≥1.1 с между запросами, lock-файл).
- Поддерживают offline-режим с ошибкой при отсутствии или истечении кэша.
- Не зависят от osmnx, networkit или blocksnet.
- Полностью офлайн-тестируемы с синтетическими данными.

Endpoint по умолчанию: `https://overpass-api.de/api/interpreter`. Оператор может заменить на другой Overpass-инстанс. Лицензия данных: ODbL, © OpenStreetMap contributors.

## Чего эти адаптеры не делают

- Не строят граф и не вычисляют маршруты — это задачи E07.
- Не вычисляют дефициты и не назначают мощности — это задачи E08.
- Не определяют расчётное окружение — это решение E07 с обоснованием.
- Не заменяют правовые проверки — POI в OSM не доказывает открытость для туристов.
- Полнота `complete` относится к ответу Overpass, не к реальному покрытию территории.

## Последствия

- Старый OSMLoader сохраняется как часть baseline; новый код его не использует.
- После реализации и тестирования адаптеров можно выполнить реальный сбор POI/сети для пилотных территорий.
- DatasetCandidate с `dataset_kind="poi"` и `"network"` позволит обновить оценку входов.
