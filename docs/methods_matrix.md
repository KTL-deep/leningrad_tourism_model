## Необоснованные пока части

| Дополнительный шаг | Метод / источник основания | Применимость, единицы и ограничения | Реализация / проверка |

| E02–E04: пригоден ли статистический набор? | Проектное правило ADR 0003/0004: программный поиск → получение → проверки → включение либо исключение с причиной; это не формула прогноза | Проверять территорию, период, единицы, покрытие и права; отсутствие не равно нулю и не требует ручного PDF | Реализована только структурная политика по утверждениям адаптера и связка со снимками; поиск/содержательные проверки ещё нет. - Целевой бесплатный многоисточниковый конвейер сам обнаруживает и получает официальную статистику и проверяет происхождение, период, единицы, охват и условия; разрешённый проверенный кэш допустим с датой/качеством. При неудаче набор исключается из численного расчёта с причиной и статусом unknown, без нуля и обязательного PDF каждого города/пользовательского CSV. Условный расчёт не заменяет отсутствующих D/K и не снимает требований к сети, геометрии и законности. Первый поиск границы реализован; поиск официальной статистики и полный многоисточниковый конвейер ещё нет.
- Отзывы — необязательный качественный слой только из разрешённых документированных API/поставщиков; соответствующий адаптер не реализован. `rating_count`, `text_review_count` и размер корпуса не смешивать; число отзывов не измеряет посещения, D или K, дата публикации не устанавливает дату визита. Темы требуют независимого подтверждения; Yandex Organization Search API не документирует выдачу текстов отзывов и является платным продуктом, поэтому не объявляется готовым API отзывов или обязательным источником.
- Новый/индуцированный спрос: S3/S4 лишь кандидаты; нет локальной калибровки, внешних альтернатив и варианта «не ехать». Процент прироста не рассчитывается.
- Вместимость услуг, сезонное распределение и время пребывания: действующих проверенных параметров пока нет. Годовые посещения не раскладываются равномерно по часам автоматически.
- Экологический предел C: применимая методика и нормативные численные пределы для пилота не установлены; C остаётся unknown, не вычисляется через площадь или A.
- Неопределённость: на старте — unknown и обоснованные интервалы при наличии основания. Произвольная вероятность достоверности не назначается; первичный источник выбранного метода анализа неопределённости ещё найти.
- Новизна и преимущество сетевого метода — гипотеза E14, не результат текущего аудита.
