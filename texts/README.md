## Тексты (заготовки)

Эта папка предназначена для хранения **текстовых описаний территорий/объектов** (например, для последующего шага анализа/скоринга туристической привлекательности).

### Что внутри

- `region_roshchino.txt` — пример краткого описания населённого пункта
- `region_gatchina.txt` — пример описания города/центра притяжения
- `poi_examples.txt` — примеры описаний точек интереса (POI) и шаблоны полей

### Рекомендации по формату

- Кодировка: **UTF-8**
- Один файл = одна сущность (регион или POI) или небольшой набор однородных сущностей
- Если нужно машинно парсить — используйте единый шаблон полей (см. `poi_examples.txt`)
