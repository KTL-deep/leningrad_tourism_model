# План разработки

Документ описывает пошаговый алгоритм реализации предиктивной параметрической модели полифункционального развития территорий в виде интерактивной веб-системы.

---

## 1) Пространственная дискретизация (Кадастровое деление)

**Цель:** Получить набор полигонов, покрывающих исследуемую территорию, строго на основе кадастровых границ для обеспечения реалистичности проектных решений.

**Ключевые задачи:**
- Загрузить границы территории и актуальные кадастровые данные (участки, кварталы).
- Заменить алгоритм нарезки пространства физическими барьерами (дороги, реки) на формирование блоков по границам кадастровых контуров.
- Привести данные к метрической системе координат (UTM).
- Отфильтровать топологические артефакты и назначить стабильные идентификаторы (`block_id`).

**Артефакты этапа:**
- `GeoDataFrame`/GeoJSON с кадастровыми блоками.
- Валидированная топология без наложений геометрий.

## 2) Семантическая экстракция и агрегация данных

**Цель:** Сформировать исчерпывающий вектор атрибутов для каждого сгенерированного блока.

**Ключевые задачи:**
- Выгрузить сырые пространственные данные из OpenStreetMap (OSM) через связку OSMnx и GeoPandas.
- Провести строгую классификацию OSM-тегов (парки, площадки, жилая и коммерческая застройка).
- Использовать методы пространственного соединения (spatial join) для корректной агрегации вложенных геометрий (например, детских площадок внутри парков) в пределах кадастрового блока.
- Интегрировать данные из реестров ЕГРКН (более 5200 объектов культурного наследия) и ООПТ.

**Артефакты этапа:**
- Вектор атрибутов $X_i$ для каждого блока, включающий площади насаждений, количество ОКН, текущую застройку и бинарные ограничения.

## 3) Сценарное математическое взвешивание (AHP) и расчет пригодности

**Цель:** Определить индексы пригодности каждого блока для различных типов использования на основе заданных стратегий развития.

**Ключевые задачи:**
- Внедрить матрицу 23 факторов оценки, разделенных на 6 макро-групп.
- Реализовать расчет весовых коэффициентов методом Аналитического иерархического процесса (AHP).
- Настроить программную проверку отношения непротиворечивости (CR $\le 0.10$).
- Сформировать три базовых сценария развития: Экоцентризм, Историко-центризм, Инфраструктурный.
- Вычислить агрегированный индекс пригодности ($S_{ik}$) по алгоритму взвешенной линейной комбинации (WLC).

**Артефакты этапа:**
- Массив рассчитанных индексов $S_{ik}$ для множества сценариев (Land Use Suitability Analysis).

## 4) Сетевой анализ и алгоритмическая оптимизация (BlocksNet)

**Цель:** Назначить каждому блоку оптимальный тип застройки (Target Land Use) с учетом транспортной доступности и разрешения пространственных конфликтов.

**Ключевые задачи:**
- Сгенерировать интермодальный транспортный граф (пешеходные, автомобильные, ж/д пути) и рассчитать матрицу изохронной доступности.
- Преобразовать баллы пригодности в параметр «обслуживающей мощности» (Capacity).
- Настроить и запустить алгоритм глобальной оптимизации — имитацию отжига (Simulated Annealing).

**Артефакты этапа:**
- Предписанный оптимальный паттерн застройки (Target Land Use) и расчетная мощность для каждого полигона.

## 5) Разработка интерактивного картографического веб-интерфейса

**Цель:** Упаковать вычислительный бэкенд в систему поддержки принятия решений (DSS) для стейкхолдеров.

**Ключевые задачи:**
- Разработать пользовательский интерфейс на базе фреймворка Streamlit.
- Реализовать кэширование предрассчитанных конфигураций графов для ускорения рендеринга.
- Настроить динамический рендеринг карты через библиотеку Folium с цветовой дифференциацией полигонов «на лету».
- Внедрить HTML-карточки (popups) с выводом атрибутики при клике на блок (площадь, текущее использование, предписанный тип, значения пригодности).

**Артефакты этапа:**
- Рабочее веб-приложение с динамическим пересчетом сценариев развития.
