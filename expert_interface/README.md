# Интерфейс экспертной оценки (AHP Weights)

Этот модуль предназначен для сбора экспертных мнений о значимости факторов туристической привлекательности.

## Как запустить
1. Установите зависимости (если еще не установлены):
   ```bash
   pip install streamlit pandas
   ```
2. Запустите приложение:
   ```bash
   streamlit run app.py
   ```

## Как это работает
1. Эксперт выбирает **Сценарий** (например, Экоцентризм) и **Тип территории**.
2. С помощью слайдеров выставляется относительная значимость факторов (от 0 до 10).
3. Приложение автоматически нормализует веса (сумма всегда равна 1.0).
4. Нажатие кнопки **"Сохранить оценку"** создает JSON-файл в папке `expert_interface/results/`.

## Интеграция
Сохраненные файлы можно использовать для перерасчета средних весов в `configs/ahp_constants.json`.
