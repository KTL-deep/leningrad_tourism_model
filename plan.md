# План разработки веб-интерфейса (Шаг 5)

Интерактивный дашборд — это "витрина" предиктивной модели, преобразующая сухие вычисления в наглядную Систему Поддержки Принятия Решений (DSS) для урбанистов и инвесторов.

## 1. Зависимости
В первую очередь я обновлю `requirements.txt`.
Для запуска дашборда потребуются:
- **`streamlit`**: современный фреймворк для веб-приложений на Python.
- **`folium`**: Python-обертка над Leaflet.js для интерактивного рендеринга геометрии.
- **`streamlit-folium`**: мост (компонент) для встраивания карт Folium в интерфейс Streamlit.
- **`matplotlib`**: для генерации цветовых градиентов (colormaps) к нашим баллам привлекательности.

> [!WARNING]
> Вам будет необходимо установить эти зависимости через терминал после завершения их добавления: `pip install -r requirements.txt`.

## 2. Архитектура приложения `app.py`
Я создам новый файл верхнего уровня `app.py`. Он будет отвечать за UI.

**Боковая панель (Sidebar):**
- Заголовок и логотип/описание концепции (Leningrad Tourism Model).
- Сводная статистика из загруженного файла: общее количество проанализированных блоков, максимальный и средний балл AHP.
- Интерактивный ползунок **"Показать Топ-N блоков"** (отфильтровать блоки с самым низким рейтингом, чтобы сфокусироваться только на зонах с наивысшим потенциалом).

**Основной экран (Дашборд):**
- Загрузка GeoJSON слоя `data/processed/ucm_blocks_with_attractiveness.geojson` с кэшированием `@st.cache_data` (чтобы карта не перерисовывалась с нуля при каждом клике).
- Рендеринг полигонов `Folium`: цвет полигона (Choropleth) будет интерполироваться от бледно-желтого (плохая пригодность) до насыщенно-красного или зеленого (высокая пригодность) на основе параметра `attractiveness_score`.
- **Интерактивные всплывающие окна (Popups/Tooltips)**: при наведении мыши на блок будет появляться красивая HTML-карточка с информацией:
  - ID блока
  - Тип доминирующего использования участка
  - AHP Score (Балл)
  - AHP Rank (Рейтинг по региону)
  - Количество памятников/леса/отелей.

## 3. Рабочий процесс
1. Обновляем требования и ставим библиотеки.
2. Пишем логику загрузки кэша в `app.py`.
3. Пишем рендерер Folium: настраиваем цвета и всплывающие окна `GeoJsonTooltip`.
4. Запускаем: `streamlit run app.py`.
