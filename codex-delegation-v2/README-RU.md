# Codex CLI: экономное делегирование v2 — вход через ChatGPT Plus

Система использует текущую авторизацию `codex login` через ChatGPT. API-ключ не нужен. Plus имеет лимиты использования; подагенты также расходуют доступный ресурс. **Подагенты не гарантируют экономию**: они полезны для изоляции контекста и самостоятельных подзадач.

## Состав
- `.codex/config.toml` — по умолчанию gpt-6-luna/low для подагентов, максимум 2 параллельных подагента, модель главного агента не меняется.
- `.codex/agents/explorer.toml` — узкий поиск в репозитории (Luna/low).
- `.codex/agents/implementer.toml` — реализация (Sol/medium).
- `.codex/agents/reviewer.toml` — выборочная проверка риска (Sol/high).
- `AGENTS.md` — динамическая стратегия выбора, ограничение контекста как рекомендации, эскалация после ошибок.
- `tools/usage_log.py` — локальный ручной учёт сессий (CSV). **Не извлекает реальные токены из подписки**.

## Установка Windows
1. Распакуйте архив. В PowerShell перейдите в нужный репозиторий `cd C:\path\to\repo`.
2. Скопируйте из папки `codex-delegation-v2` директорию `.codex` и `AGENTS.md` в корень репозитория (можно вручную в Проводнике).
3. Если эти файлы уже существуют, **не перезаписывайте**: объедините `AGENTS.md`, а `[agents]` и файлы агентов перенесите в старую конфигурацию.
4. `codex --version`, `codex login status` (если ваша версия поддерживает), затем `codex`.
5. Внутри Codex используйте `/model` и убедитесь, что роли могут запускать выбранные модели. При отказе замените `model = ...` в TOML на доступные варианты.

## Проверка (без записи файлов)
В Codex: `Используй explorer, чтобы найти точку входа проекта. Ничего не меняй. Укажи реально использованную модель/роль, если эта информация доступна.`

## Работа по умолчанию
Обычный запрос: `Исправь ошибку ...; используй политику делегирования из AGENTS.md и минимизируй расход контекста.`
Принудительная проверка: `Попроси reviewer независимо проверить этот diff и перечислить только реальные дефекты.`

## Учёт прогресса
Из PowerShell в папке проекта (при наличии Python):
`python tools/usage_log.py add --task "Исправить поиск" --route "explorer+implementer" --result pass --minutes 12 --attempts 1 --notes "тесты прошли"`
`python tools/usage_log.py report`
CSV лежит в `.codex-local/usage.csv` (добавьте эту папку в `.gitignore`).
Это ручной журнал, без доступа к лимитам Plus или детализации токенов. Для реальных цифр используйте доступные показатели `/status` / интерфейса Codex; возможности зависят от версии.

## Что не автоматизировано
- Codex на основании AGENTS.md самостоятельно решает, когда вызывать роль: это **инструкция модели**, не жёсткая классификация движком.
- Контекстные бюджеты в AGENTS.md ориентировочные, не аппаратный `max_tokens`.
- Никаких API-платежей и отдельного маршрутизатора в этой версии нет.
